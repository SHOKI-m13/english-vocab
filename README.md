# 英単語ノート

Lesson 7 の37語と Lesson 8 の47語を、英日・日英の両方向で反復する静的Webアプリです。

## ローカルで起動

Node.js 20 以上で次を実行し、ブラウザで `http://localhost:4173/` を開きます。パッケージのインストールは不要です。

```sh
node serve.mjs
```

ロジックのテストは `node --test` で実行できます。

## 静的ホスティング

GitHub Pages の公開元をリポジトリのルートに設定するか、静的ホストに `index.html`、`style.css`、`app.js`、`study.js`、`words.js`、`sw.js`、`manifest.webmanifest`、2個のPNGアイコンを配置します。すべてのアセットは配置先からの相対パスで読み込みます。

PWAには HTTPS または localhost が必要です。一度オンラインで読み込んでから、対応ブラウザのメニューでホーム画面に追加できます。学習記録は端末のブラウザ内に保存されます。

## 学習記録の集計

- 苦手単語は、どちらかの方向で累積正答率が75%未満、または累積不正解が2回以上の単語です。選択時の対象を一周の終了まで保持します。
- 総学習回数は、各サイクルで最初の回答をしたときに加算します。学習時間は、学習カードが表示されている間の前面表示時間を集計します。
- 学習範囲や出題方向の変更時はラウンドを組み直します。各方向の連続正解と累積記録を引き継ぎます。
- 画面の暗記達成率は選択中の出題項目に対する割合です。単語の完全暗記は両方向の達成で数えます。
